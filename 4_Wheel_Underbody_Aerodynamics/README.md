# Project 4 — Wheel and Underbody Aerodynamics

## Objective

Investigate airflow around wheels, wheel arches, and vehicle
underbodies.

## Planned Investigations

- Ground clearance
- Rotating versus stationary wheels
- Wheel-arch flow
- Underbody velocity distributions
- Ground-effect sensitivity

## Current Status

Planned. Rotating-wheel and underbody simulations have not yet
been implemented or validated.
